- 背景：小胡发现 glm-5.2 不太顺畅，切到 kimi-k3 顺畅。要求给 default model 加 fallback。

  - fallbacks: `["custom-llm-gateway-mlamp-cn/mlamp/kimi-k3"]`

- 后续：如果 glm-5.2 长期不稳定，考虑直接换 primary；如果只偶发，让 fallback 自然兜底
