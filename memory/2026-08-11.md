### 踩坑
1. `channels.octo: unknown channel id: octo` — 需要在 `plugins.entries` 里显式启用 `octo: {enabled: true}`
2. `gateway.mode is unset` — doctor 会检查 gateway.mode 必须设为 local
3. launchctl bootstrap 报 I/O error — 需要先 bootout 再 bootstrap
