# 工程实施风险审核清单

**触发条件：** 当需求信息足够详细（到了功能点/接口层面）时自动触发。纯粗略描述跳过，不硬审。

## 维度1 — 界面回显对齐

- 功能在界面是否已有对应入口
- 如果涉及API任务，结果是否需要回显到界面
- 过滤条件、Table拆分逻辑在界面和API两侧是否一致

## 维度2 — 权限适配

- 活动级权限是否覆盖
- 跨活动数据请求的权限校验
- API Key归属和权限范围
- 脱敏规则一致性

## 维度3 — 数据逻辑对齐

- 指标计算口径是否明确（acc/day/all、net/totalnet）
- 衍生指标公式是否需要定义
- 空值和时区处理

## 维度4 — 异步任务工程风险

- 大数据量是否需要异步执行
- 并发控制
- 超时处理
- 幂等性
- 回调机制

## 维度5 — 边界场景

- 无数据/空结果处理
- 超限截断
