# 已知约束清单

> AdMonitor 知识参考材料，用于需求审核粗判。标记"知识参考，非最终判断"。

## 数据口径约束

| 约束 | 说明 | 影响 |
|------|------|------|
| 实时 ≠ 基础 | 实时数据未经GIVT过滤，基础数据经过GIVT过滤 | 实时 > 基础是常态，不是BUG |
| Net ≠ TotalNet | Net仅过GIVT，TotalNet过GIVT+SIVT | 和媒体对数时过滤类型不一致会导致GAP大 |
| UV不能跨时间段加总 | 同一用户不同天可能重复计入 | 需用acc累计值而非day逐天相加 |
| by_audience=target时day无效 | target维度不返回day指标 | 返回0或null，不是BUG |
| overall维度无Universe | Universe仅stable维度有 | — |
| PM平台无行为异常数据 | 打通后看不出单端行为 | 查行为异常需选pc或mb |
| 相交样本量<300不可参考 | 统计学置信度不足 | 数据会标红 |
| TVM无点击数据 | OTT设备无点击行为 | — |
| day出现负数 | acc数据计算有误 | 需重算活动 |
| 已结束活动拉数 | date必须用活动结束日期，不能用今天 | 报 date is out of campaign period |

## 分页约束

| 约束 | 说明 |
|------|------|
| ADM默认500条 | limit=0,500，必须翻页直到返回<500 |
| TVM默认300条 | limit=0,300 |
| TVM campaigns/list最大50/页 | pageSize最大50 |
| 不翻页会静默丢数据 | 返回500条但实际可能更多 |

## 地域约束

| 约束 | 说明 |
|------|------|
| ADM和TVM地域码不同 | 两套独立体系，不能混用 |
| ADM中国大陆 | 000000000000000000000008 |
| TVM中国大陆 | 1156000000 |
| S2S影响地域判定 | 秒针拿到的是媒体服务器IP，非用户IP |
| IPv6/IPv4跨协议差异 | 同源媒体不支持IPv6时rawip和nsip协议不一致 |

## 时间约束

| 约束 | 说明 |
|------|------|
| 基础数据T+1 | 次日10:00完成 |
| IVT数据T+1 | 次日12:00完成 |
| 分地域/TotalNet | 次日20:00完成 |
| 拉数前必须查计算进度 | progress接口的date >= 你要拉的date |
| M+任务时间范围 | 2014.6.1起，之前日志不全 |
| M+自定义维度≥2个时 | 时间范围只能选单日 |
| 多维查询日期跨度 | ADM不超过3个月 |
| 所有查询日期 | 不能晚于昨天（T+1） |

## GAP相关约束

| 约束 | 说明 |
|------|------|
| GAP客观存在 | 网络丢失导致，不可能完全消除 |
| 行业参考范围 | <10%（不分平台），但实际可接受范围因客户而异 |
| GAP排查顺序 | 先查维度对齐（最便宜）→ 再查加码 → 最后查计算 |
| S2S不回传设备ID | 触发无效用户过滤，UV/Clicker/TA出问题 |
| 媒体数据有过滤 | 媒体可能用了过滤后数据对比秒针基础数据 |

## IVT相关约束

| 约束 | 说明 |
|------|------|
| GIVT在ETL阶段执行 | 4条规则，所有客户通用 |
| SIVT分三级 | 标准版/高阶版/H2 |
| SIVT指标仅day | 无acc累计 |
| SIVT仅overall | 不支持by_audience |
| SDK签名校验 | KA专属功能，不对外 |
| 非MZSDK流量 | KA专属，粗筛是否秒针SDK发的 |
| OTT SIVT独有规则 | 无效ID曝光/开机频繁/曝光频繁/可疑机型/非签名/夜间/多城市/新增设备 |
| 部分SIVT不纳入定量化 | 无曝光点击/新版高危IP/合法设备ID/设备白名单 |

## API限制约束

| 约束 | 说明 |
|------|------|
| token有效期1小时 | 过期需重新获取 |
| M+ passport token ≠ ADM OAuth token | 不同体系，不能混用 |
| M+ advertiserId/campaignId必须是string | int类型返回500 |
| M+ spotIdStr需要62进制 | 不能用十进制 |
| M+ taskName不可重复 | 重复提交报错 |
| 多维查询限流 | 创建任务有频率限制 |
| 429触发限流 | 读Retry-After等待 |

| 能力 | 说明 |

| Daily Alert | 定时邮件告警 |
| 实时日志抽样查询 | 每小时前十条，发邮箱 |

## 账号/活动结构约束

| 约束 | 说明 |
|------|------|
| 同一客户多个账号 | 主账号/产品线子账号/代理商账号，需查广告主列表判断 |
| 活动<100万 | 无人群分析模块 |
| 活动100万~200万 | 无个性分析模块 |
| 活动≥200万 | 全功能+实时5分钟更新 |
| 排期外日志 | 不参与计算但分类输出 |
| 报表保留 | 至少两年 |
